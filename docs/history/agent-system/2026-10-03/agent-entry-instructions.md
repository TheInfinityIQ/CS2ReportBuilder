# Agent entry point

Read [CLAUDE.md](CLAUDE.md), then [agent/STATE.md](agent/STATE.md). Follow the task
router and source-of-truth map. For file discovery, open [00_INDEX.md](00_INDEX.md)
and only the folder map relevant to the task; see [docs/NAVIGATION.md](docs/NAVIGATION.md).

After adding, editing, moving, or deleting source files, refresh navigation and
run its check. A curated summary whose source changed needs a deliberate review.
Generated maps are discovery aids, not authority. Fresh coaches use only their
isolated packet; do not give them these agent instructions or navigation maps.
