# Documentation cleanup — first batch

Date: 2026-10-03. Authorized by Dawson after reviewing the plan and delegating
evidence-backed technical choices. Additional agents require approval for a
specific task or bounded group; none were used for this cleanup.

## Change and rationale

- README.md is the master entry page. AGENTS.md holds one working agreement;
  CLAUDE.md imports it instead of maintaining duplicate rules. The workspace
  pointer is local, with no automatic import of history or indexes.
- PROJECT_STATUS.md separates observed artifacts, known gaps, and verification.
- Seventeen former startup/procedure sources were preserved in the
  [agent-system archive](history/agent-system/2026-10-03/README.md).
  [MIGRATION.json](history/agent-system/2026-10-03/MIGRATION.json) records paths
  and hashes. The old agent folder and its generated maps were retired.
- Historical decision, preference, critique, and roadmap documents are explicitly
  nonbinding during the reset. Source bodies remain available. Current state does
  not require reconciling obsolete claims scattered through old instructions.
- Navigation is optional. The generator is retained for existing freshness CI;
  its redesign is not mixed into this migration.
- Documentation checks now verify usable current links and archived source
  integrity instead of enforcing hats and arbitrary line caps. Relevant product
  checks and coach-input isolation checks remain.
- Local legend entry references and the versioned snapshot were refreshed.
  Existing coach runtime templates, saved packets, analysis and demos are unchanged.

Anthropic recommends broadly useful startup instructions, retrieving detailed
context when needed, and verification plus progress records for long-running
work. Those principles motivate this structure; these exact filenames and
archive destinations are engineering choices:
[coding guidance](https://code.claude.com/docs/en/best-practices),
[context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents),
[continuity guidance](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents).
The compatibility import follows their
[memory documentation](https://code.claude.com/docs/en/memory).
