## Research basis and limits

[Anthropic context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
supports retaining lightweight references and retrieving detail as needed.
[Claude Code best practices](https://code.claude.com/docs/en/best-practices)
supports keeping startup instructions broadly useful and excluding file-by-file
descriptions. [Long-running agent harness guidance](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)
supports recoverable progress records and checking outcomes rather than assuming
success from produced artifacts. The particular archive layout and filenames
are engineering choices, not Anthropic requirements.

No new agent benchmark or billed-token measurement was performed. Representative
retrieval checks establish reachability and useful source routing only. The
earlier six-pair character-count pilot remains the evidence for mixed index costs.
Known source paths can be opened directly without any map detour.
